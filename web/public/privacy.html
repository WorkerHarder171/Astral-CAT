Kebijakan Privasi Astral Cat

Terakhir Diperbarui: 18 November 2026 • Berlaku untuk semua pengguna dan server Discord yang menggunakan Astral Cat.

📌 Ringkasan Komitmen Privasi Kami

Astral Cat diciptakan untuk menyediakan utilitas komunitas, musik, kartu sambutan, dan pengaturan server Discord. Kami TIDAK PERNAH membaca, merekam, atau menyimpan percakapan obrolan pribadi Anda (chat logging). Kami tidak menjual data Anda kepada pihak mana pun, dan hanya memproses data teknis yang mutlak diperlukan untuk fungsionalitas bot.

01 Informasi & Data yang Kami Kumpulkan

Ketika Anda atau administrator mengundang dan berinteraksi dengan Astral Cat di server Discord, bot dapat menerima data berikut langsung melalui Discord API:

  • Pengenal Unik Discord (Snowflake IDs): Discord User ID, Server (Guild) ID, Channel ID, dan Role ID untuk memvalidasi izin, mengarahkan tujuan pesan pengumuman, dan memberikan role gender yang dipilih.
  • Informasi Profil Publik: Username, Discriminator/Tag, dan URL foto profil (Avatar) publik dari pengguna. Informasi ini hanya digunakan secara sementara pada memori mesin untuk merender kartu selamat datang (Welcome Card Canvas).
  • Status Voice Channel (Voice States): ID voice channel dan status sambungan pengguna ketika menggunakan perintah musik (seperti !play atau !stop).
  • Input Perintah & Interaksi: Pesan yang diawali dengan prefix bot (misal: !) atau klik tombol/modal interaksi untuk menjalankan aksi yang diminta.

02 Data yang TIDAK Pernah Kami Kumpulkan

Untuk menghindari keraguan, Astral Cat TIDAK PERNAH:

  • Merekam atau menyimpan isi pesan teks umum yang tidak ditujukan sebagai perintah bot.
  • Mengumpulkan kata sandi (password), informasi penagihan/finansial, atau identitas nyata di dunia nyata.
  • Merekam atau menyimpan data audio mikrofon pengguna di Voice Channel.
  • Mengakses atau mengintip Direct Messages (DM) pribadi pengguna di luar tombol verifikasi gender yang diminta.

03 Tujuan Penggunaan Data

Data yang diterima hanya digunakan untuk tujuan fungsionalitas murni:

Pemutar Musik

Menyambungkan bot ke voice channel pengguna dan mengelola antrean lagu.

Kartu Sambutan Dinamis

Menggambar avatar dan nama member baru di atas banner ucapan selamat datang.

Pemberian Role Gender

Menambahkan role Man/Woman pada profil anggota saat tombol diklik.

Penerbitan Pengumuman

Mengirimkan pesan berformat embed ke channel yang telah ditentukan admin.

04 Penyimpanan & Retensi Data

Astral Cat tidak menggunakan database cloud eksternal pihak ketiga untuk melacak aktivitas pengguna.

  • Konfigurasi Server: ID channel sambutan, ID channel pengumuman, dan ID role disimpan secara lokal dalam file konfigurasi lingkungan (.env) pada host server bot.
  • Antrean Musik (Queue): Disimpan hanya di RAM (memori sementara) selama bot aktif. Antrean lagu akan otomatis terhapus secara permanen saat pemutaran selesai atau bot meninggalkan voice channel.

05 Integrasi Layanan Pihak Ketiga

Astral Cat berinteraksi dengan beberapa antarmuka pemrograman aplikasi (API) pihak ketiga yang memiliki kebijakan privasi masing-masing:

  • Discord API (Discord Inc.) — Sebagai platform operasional utama bot.
  • YouTube / Google LLC — Untuk mengekstrak streaming audio lagu bebas hak cipta atau publik.
  • Spotify Web API — Untuk membaca metadata judul lagu dan daftar putar yang dicari pengguna.

06 Hak Pengguna & Permintaan Penghapusan Data

Sesuai dengan regulasi privasi global dan Discord Developer Policy:

  • Penghentian Layanan: Administrator server dapat mengeluarkan (kick) atau memblokir (ban) bot dari server mereka kapan saja untuk menghentikan pemrosesan data secara instan.
  • Penghapusan Konfigurasi: Anda dapat menghapus channel atau ID konfigurasi server melalui Dashboard Pengaturan.

Hubungi Kami

Jika Anda memiliki pertanyaan, saran, atau permintaan terkait privasi dan perlindungan data bot Astral Cat, silakan hubungi pengembang melalui repositori resmi atau kontak server komunitas.
