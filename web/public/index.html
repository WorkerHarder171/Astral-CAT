Fitur Unggulan

Dirancang khusus untuk menghadirkan kenyamanan komunitas server dan kemudahan pengaturan administrator.

🎵

Hi-Fi Music Player

Putar musik tanpa jeda dari YouTube dan Spotify. Dilengkapi fitur antrean interaktif, pencarian lagu cepat, skip, pause, dan kontrol volume.

!play, !skip, !queue, !np
🎨

Canvas Welcome Banner

Pembuatan gambar sambutan otomatis beresolusi tinggi menggunakan teknologi Canvas dengan avatar bundar anggota baru dan nama pengguna tercetak jelas.

!test-welcome, !setup-welcome
🚻

Sistem Claim Role Gender

Kirim pesan sambutan DM otomatis dengan tombol pemilihan role Man (♂️) dan Woman (♀️), serta panel interaktif di channel server.

!setup-role, auto-DM join
📢

Announcement Builder

Buat pengumuman rapi menggunakan pop-up modal interaktif Discord dengan template siap pakai: Stream, Maintenance, Event, dan Informasi Umum.

!announce, !announce-all
⚙️

Web Dashboard Pengaturan

Kelola seluruh konfigurasi bot secara langsung melalui browser web lokal tanpa perlu menyunting file kode secara manual.

http://localhost:3000/settings
⚡

Utilitas & Monitoring

Cek kecepatan respon bot dengan sistem perhitungan ping ganda (pesan vs websocket gateway) dan direktori bantuan perintah lengkap.

!ping, !help, !bantuan
